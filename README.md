# Reyon S. Portfolio

An interactive, scroll-driven 3D portfolio book based on the materials supplied in this repository.

## View

Open `index.html` in a browser, or enable GitHub Pages for this repository to publish it. Scroll to turn the pages, use the on-screen arrows, or press the left/right arrow keys. The navigation buttons jump directly to portfolio chapters.

## Included materials

- `Polished 3D Hijab Portrait.png` — portrait artwork used in the portfolio.
- `Reyon S Book Portfolio (1).zip` — source portfolio archive.
- `Reyon_S_Resume.pdf` — downloadable résumé.

The page is plain HTML, CSS, and JavaScript. The portrait and résumé links point to the files in the repository. Google Fonts are optional; system serif and sans-serif fallbacks are included.
